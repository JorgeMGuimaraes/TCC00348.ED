# Arquivos

* Definição de arquivos;
* Tipos de arquivos: binários e de texto;
* Funções para manipulação de arquivos em C (biblioteca stdio.h): fopen e fclose para abrir e fechar arquivos, respectivamente; 
* fscanf e fprintf para leitura e escrita de informações em arquivos texto, respectivamente; e 
* Exemplos de uso das funções: merge de dois arquivos texto ordenados, gerando um terceiro também ordenado.
